## 2. 语言长什么样

下面是本规范语法下的四位计数器，完整文件见 [counter.vmc](../examples/valid/counter.vmc)。

```text
language "0.1";
package examples;

module Counter(width: nat = 4) {
    require width >= 1;
    input clk: clock;
    input reset: bit;
    input enable: bit;
    output count: uint<width>;

    reg value: uint<width> reset u(width, 0);

    on rising(clk) reset(reset) {
        if enable {
            next value = wrapAdd(value, u(width, 1));
        }
    }

    connect count = value;
}
```

每个实例有自己的一组寄存器和组合硬件。`width` 是编译期参数；`u(width, 1)` 是定宽无符号常量；`wrapAdd` 明确表示按位宽回绕。

`reg ... reset ...` 声明复位值，并不在加载设计时强行写入该值。`on rising(clk) reset(reset)` 表示在时钟上升沿同步检查高有效复位；复位优先于代码块中的更新。`enable` 为假时，`value` 保持原值。

## 3. 文件、字符与词法

- 源文件扩展名为 `.vmc`，UTF-8 编码，可有文件开头 BOM。标识符只使用 ASCII 英文字母、数字和下划线，首字符必须是字母；注释与字符串可用中文。区分大小写。
- 每个文件以 `language "0.1";` 和 `package name;` 开头。未知语言版本报错，不猜测兼容规则。
- 语句使用分号，块使用花括号，换行只分隔空白。参数、实参、数组和枚举列表不允许尾逗号。
- `//` 为行注释；`/* ... */` 为不嵌套块注释。注释不能出现在字符串内部，也不能把一个数字或标识符拆成两个片段后拼接。
- 标识符词法为 `[A-Za-z][A-Za-z0-9_]*`。风格检查建议值名称 lowerCamelCase、模块/组件/枚举名称 UpperCamelCase；风格警告不改变语义。
- 无类型整数字面量支持十进制、`0b` 二进制、`0x` 十六进制。下划线只能出现在两个合法数字之间；十进制除 `0` 外不能以 0 开头。负号是运算符，不属于数字词法。
- `true`、`false` 为 `bit` 常量。没有浮点数、字符字面量和隐式字符串插值。
- 字符串采用 JSON 双引号与转义规则，不允许原始换行；Unicode 转义必须构成合法 Unicode 标量值。字符串只用于版本、路径、组件键、测试消息等元数据，不能成为硬件信号。
- 多字符运算符按最长匹配读取；`>>` 是移位，两个类型结束符在嵌套类型中按文法解释。0.1 的聚合用 `[T; N]`，不产生嵌套角括号类型。

保留字如下；内置函数名不是保留字，函数调用按独立的调用名称空间解析，不能被用户函数重定义。值可以与内置函数同名，例如输入 `b` 和常量构造 `b(4, 3)` 可以共存：

```text
language package import as const enum fn return module cell source
require input output wire reg reset inst unused connect comb let
if else match case default on rising next generate for in
bit bits uint int level clock nat integer true false
build target library bounds period high setup hold settle port at face
stride map using place facing route auto objective volume materials
test mode logical physical drive expect message cycle repeat sample watch
north south west east up down gt rt
```

## 4. 名称、导入与编译期展开

### 4.1 名称与作用域

顶层可声明常量、枚举、函数、模块、组件、构建配置和测试。用户声明名在同一作用域唯一，不能遮蔽外层可见用户名称或导入别名。函数调用先解析本地/限定用户函数，再解析同名内置函数；禁止用户函数重定义内置函数，因此不存在选择歧义。关键字作为固定语法位置不参与名称冲突，例如 `reset(reset)` 中第二个 `reset` 是端口名的特别许可，见文法的 `name` 规则；除此之外保留字不可用作名称。

**唯一特别许可：`reset` 可作为端口、wire、reg、参数、常量和局部 let 的名称。** 这是为了让复位端口使用自然名称；不能用它命名模块、类型、函数、包、枚举成员或导入别名。`reset` 出现在声明指令位置时仍是关键字。其余保留字不设例外。

模块内的硬件声明可前向引用，所有连接一起建立；`const`、参数默认值与函数内 `let` 只能引用此前可见的编译期/局部声明。顶层模块、类型与函数可以前向引用，但调用、类型依赖和实例化不得形成递归环。

`child.outputName` 读取直接子实例的输出，`child.inputName` 只能作为连接目标。不能穿透子模块访问寄存器或内部实例。自己的输入、输出、wire 和 reg 可以作为表达式来源。输出被读取不使它成为可写变量。

生成块用 `lanes[0].unit.y` 访问展开的成员；下标必须在编译时确定。层级路径不是任意对象成员访问或运行时索引。

### 4.2 文件与依赖

```text
import "adder.vmc" as arithmetic;
inst sumUnit: arithmetic::Adder(width = 4);
```

导入路径相对于所在源文件解析，必须指向项目根内或锁定依赖根内的真实文件。禁止网络导入、目录隐式搜索、符号链接逃逸和导入环。全部顶层声明可被限定名称引用；0.1 没有通配导入、重导出或可见性修饰符。

`package` 是源文件的逻辑归属，不进行路径搜索。同包文件也必须显式导入；一个包内顶层符号名不得重复。`alias::Name` 表示导入文件的符号；`State::idle` 表示枚举成员。通过首段解析类别确定含义，冲突报错。

### 4.3 参数、常量与有限生成

模块参数只允许 `nat`、`integer`、`bit`，均在编译时确定。`nat` 为非负任意精度整数，`integer` 为有符号任意精度整数；受资源预算限制，不能以宿主 C++ 溢出处理。所有实例参数按名传递，每项至多一次；缺少无默认值参数、未知参数或错误类型均报错。

`const name: type = expression;` 保存编译期值。无类型整数只能留在编译期，不能被赋给运行时信号；nat/integer 之间及无类型整数到它们的转换允许按数学整数赋值，并在 nat 边界检查非负。`require condition;` 要求编译期 `bit` 为真，否则终止该实例展开并显示实例路径。

```text
generate lanes for i in 0..width {
    inst unit: BitBuffer;
    connect unit.a = a[i];
    connect y[i] = unit.y;
}
```

范围为左闭右开，边界为 `nat`，结束小于开始报错。零次展开合法，但不豁免输出完整驱动检查。索引 `i` 在当前展开内为常量，每次迭代是独立作用域。生成块只允许常量、require、wire、实例、连接、unused、comb 和嵌套生成块，不能生成顶层端口、reg 或时钟块；需要状态时实例化带状态模块。

所有数组大小和位宽为正 `nat`。类型尖括号/数组大小中的表达式只允许常量引用、整数、编译期函数调用、括号及一元符号和 `+ - * / %`；需要条件或比较时先声明 const，再引用该名称。0.1 基准配置允许位宽 1–4096、单个数组长度 1–65536；展开总量另受配置预算约束，超限报错且保留诊断。限制必须写入构建清单，不能悄悄缩短数组或少生成实例。

## 5. 类型与数值

| 类型 | 取值和用途 |
|---|---|
| `bit` | `false` 或 `true`；条件必须是此类型 |
| `bits<N>` | N 位原始位向量，仅按位运算，不隐式当数值 |
| `uint<N>` | 0 至 2^N−1 |
| `int<N>` | 二进制补码，−2^(N−1) 至 2^(N−1)−1 |
| `level` | 0–15 强度；是一条强度通道，不是四位总线 |
| `clock` | 单时钟域的连接标记，无普通值运算 |
| `[T; N]` | N 个同类型元素；首版禁止元素为数组，允许标量信号类型及枚举 |
| 用户枚举 | 名义类型，只能用声明成员构造；至少两个成员 |
| `nat` / `integer` | 只用于编译期，无运行时存储 |

数组元素不能是 `clock`、`nat` 或 `integer`。`reg` 只允许 `bit`、位向量、定宽整数、枚举及这些类型的数组，禁止 `level` 和 `clock`。输入输出允许标量 `clock`；wire 允许 clock 别名，但不允许 clock 数组。

枚举成员按声明顺序编码为 0、1、2…，物理位宽为 `max(1, ceil(log2(成员数)))`。枚举不同于同宽整数，禁止数值转换。未用编码、无法解码的实测总线是诊断状态，不是任意合法成员。

赋值、连接、函数传参和条件分支结果必须类型完全一致。没有整数到 bit、位宽扩展、符号转换或 level 编码的隐式转换。

### 5.1 常量与显式转换

| 内置操作 | 参数与结果 |
|---|---|
| `u(N, k)` | 编译期 N、k，生成 `uint<N>`；k 必须在范围内 |
| `s(N, k)` | 编译期 N、k，生成 `int<N>`；k 必须在范围内 |
| `b(N, k)` | 编译期 N、k，生成 `bits<N>`；k 必须非负且适合 N 位 |
| `strength(k)` | 编译期 0–15 整数，生成 level 常量 |
| `asBits(x)` | 定宽整数或 bit 转为同宽位向量，保持比特 |
| `asUint(x)` / `asInt(x)` | bits、定宽整数或 bit 按相同比特重新解释；bit 对应一位 |
| `widen(x, N)` | uint/int 扩大或保持位宽；uint 补零，int 符号扩展；N 小于原宽度报错 |
| `low(x, N)` | bits/uint/int 取低 N 位，返回 `bits<N>`；1 ≤ N ≤ 原宽度 |
| `concat(a, b, ...)` | 至少两个 bit/bits 参数，从左到右高位到低位，返回 bits |
| `repeatBits(x, N)` | bit/bits 重复正整数 N 次，返回 bits |
| `select(c, a, b)` | 与 `c ? a : b` 相同，c 为 bit，a/b 同类型且不为 level/clock |
| `wrapAdd(a, b)` / `wrapSub(a, b)` | 同类型 uint/int，结果同宽，模 2^N 后按原符号解释 |
| `ceilLog2(k)` | 正编译期整数，返回 nat；k=1 返回 0 |

数组构造为 `[a, b, c]`，至少一个元素且类型一致，长度由元素数决定。不提供零长度向量。`asInt(u(4, 15))` 是 −1；数值 15 需要 `s(5, 15)`，两者不可混淆。

`level` 在可综合核心只支持端口、常量、直接连接及组件传递。强度检测、加减、选择、编码/解码必须显式实例化组件，类型转换不产生隐形硬件。测试表达式允许比较 level 值；可综合表达式禁止 level 比较。

### 5.2 运算符与结果宽度

除编译期无类型整数外，二元运算要求两侧类型完全一致。不存在依据左侧赋值类型改变右侧表达式宽度的上下文推断。

| 运算 | 合法操作数 | 结果 |
|---|---|---|
| `+` | 相同 uint<N> / int<N> | uint<N+1> / int<N+1> |
| `-` | 相同 uint<N> / int<N> | 均为 int<N+1>，保留负结果 |
| 一元 `-` | uint<N> / int<N> | int<N+1> |
| `&`、`\|`、`^`、`~` | 相同 bit/bits/uint/int | 同类型同位宽；bit 的 `~` 等价取反 |
| `!`、`&&`、`\|\|` | bit | bit |
| `==`、`!=` | 相同 bit/bits/uint/int/枚举 | bit；数组不支持整体比较 |
| `<`、`<=`、`>`、`>=` | 相同 uint/int | bit，按符号解释 |
| `<<`、`>>` | 左为 bits/uint/int；右为非负编译期整数 | 与左侧同类型；超出部分丢弃 |
| `c ? a : b` | c 为 bit，a/b 同类型 | a/b 类型；禁止 level、clock |

右移 bits/uint 补零，int 符号扩展。移位量等于或大于宽度时，左移与逻辑右移为零，算术右移为全符号位；不使用 C++ 对超宽移位的行为。

例：两个 uint<4> 相加得到 uint<5>；`u(4, 0) - u(4, 1)` 得到 int<5> 的 −1。将它们接到 uint<4> 必须报错。回绕可用 `wrapAdd`/`wrapSub`，取位可用 `low` 后显式重解释。

编译期 nat/integer 与无类型整数在算术中共同按数学整数计算，支持 `+ - * / %`、相等/关系比较、取负和 bit 条件选择；声明 nat 时再次检查非负。`/` 向零截断，`%` 的余数与被除数同号；除零报错。乘除取模仅限编译期，出现在硬件数值表达式中报 `EOperatorDomain`；定宽常量也不能借此绕过硬件类型规则。

### 5.3 优先级与取位

从高到低：调用/索引 → 一元 `! ~ - +` → `* / %` → `+ -` → `<< >>` → `< <= > >=` → `== !=` → `&` → `^` → `|` → `&&` → `||` → `?:`。二元运算左结合；条件运算右结合。关系和相等运算不允许连续串接，`a < b < c` 必须拆成两个比较与 `&&`。

无类型编译期整数可用一元 `+`；硬件 uint/int 的一元 `+` 保持类型。测试和编译期条件、`&&`、`||` 按选择短路判定有效性；硬件仍生成必要路径，但未选中路径的无效值不污染选中结果。静态非法类型或操作在未选中分支中也必须报错。

bits/uint/int 的 `x[i]` 返回 bit；`x[lo:hi]` 取左闭右开区间并返回 bits<hi−lo>。索引从最低位 0 开始；所有下标和片选边界必须编译期确定且在范围内，片选至少一位。数组 `a[i]` 返回 T；0.1 不支持运行时数组寻址，动态选择应写显式组合选择逻辑。

## 6. 模块、连接与实例

声明形式：`input name: T;`、`output name: T;`、`wire name: T;`、`reg name: T reset constant;`。wire 没有存储；reg 保存状态。不得声明初始通电为零之类的隐式运行状态。

`inst name: Module(parameter = value);` 或 `inst name: Cell;` 创建独立实例。实例参数配置与端口连线分开，不使用按位置连接。

`connect destination = expression;` 是持续连接。目标仅能是当前模块 output/wire 或直接子实例 input，允许编译期数组索引或位片选。它不能写当前 input、reg、子实例 output 或内部寄存器。

多位信号驱动按实际位集合检查，数组按元素再按位展开。整段与片段不能重叠，不同 connect/comb 可以负责互不相交的片段。所有 output/wire/子实例 input 的每一位必须恰有一个驱动；clock、level 和枚举是不可拆分对象。`unused child.output;` 明确标记不用的输出，不给它注入值。

wire 即使暂时无人读取也必须完整驱动；未用硬件给警告。子输出没有消费者且没有 unused 声明给警告；顶层输出可以由外部消费，不产生此警告。

表达式只允许读取合法源，不能读取子实例 input 来绕过接口。连接拓扑在展开后建立，组合依赖必须无环；寄存器边界打断依赖。时钟连接只允许同类型端口或 wire 别名；常量或 bit 不能转换成 clock。

## 7. 组合逻辑与纯函数

```text
comb {
    if chooseB {
        y = b;
    } else {
        y = a;
    }
}
```

comb 内赋值表示电路方程，不是逐行修改变量。目标规则与 connect 相同。对于该块拥有的每一位，所有语法分支路径必须恰好赋值一次。0.1 依据 if/else 和 match 的分支结构判定互斥，不尝试证明独立条件互补；即使 if 条件恒真，也必须满足完整赋值规则。先默认赋值、随后覆盖会报重复驱动；漏掉 else 导致某一路径未赋值也报错，不隐式生成锁存器。

`let name = expression;` 是不可变表达式别名，只在后续同块和子块可见。它不创建寄存器，也不允许先用后定义。if 条件必须是 bit。分支选择取决于输入/当前状态，文本顺序没有硬件执行意义。

`match value { case constant { ... } default { ... } }` 是互斥选择，不贯穿。选择值允许 bit、bits、uint、int 或枚举；case 必须是同类型编译期常量，不重复。default 至多一个且必须最后。bit 和枚举列全所有可能值时可省 default；其他类型必须有 default。恒定不可达分支不能免除语法和类型检查。

纯函数形式为 `fn name(a: T, b: T) -> R { let temp = expression; return expression; }`，无参数默认值、无泛型、无副作用、无递归。函数体仅由零个或多个 let 与一个末尾 return 组成，条件选择用 `?:`。只可访问参数、局部 let 和可见编译期常量。时钟、level 不得作为函数参数或返回值；返回类型必须一致。

函数参数可为 nat/integer，此类调用只能在编译期发生；其他函数可用于生成组合表达式。首版需要不同位宽的复用时优先使用参数化模块。

## 8. 同步状态与时钟

每个模块至多一个 `on rising(clk) reset(resetSignal) { ... }` 块。两个引用均须是当前模块输入或 clock wire 别名/bit 表达式中的合法来源：时钟必须解析为一个 clock 输入，复位必须是 bit 表达式。复位表达式的时序必须满足实现约束。

该块拥有其中所有 `next regName = expression;` 涉及的寄存器。每个声明的 reg 必须被拥有；寄存器没有更新语句时直接用 const/wire，不声明无主状态。next 仅可写完整 reg，不可部分更新其位或数组元素。

有效上升沿的逻辑步骤固定为：

1. 根据边沿前输入和旧状态求值；若复位条件无效，报告无效控制。
2. 复位条件为真时，把所有归属寄存器的 next 设为其声明的编译期复位值，忽略普通更新分支。
3. 否则执行块中的选择关系；每条动态路径上，一个 reg 最多被 next 赋值一次，未赋值保持旧值。
4. 同时提交全部 next；跨模块也使用边沿前的旧状态统一计算，再提交。
5. 根据新状态重新求组合输出。先后文本位置不改变这些步骤。

因此 `next a = b; next b = a;` 交换旧值。两个独立的 if 给同一 reg 赋值会报冲突，即使它们的条件在数学上互补也应改成 if/else；互斥判定与组合逻辑一样只依据语法分支结构。不建立“最后写入优先”。一个 if/else-if 链按从外到内的选择含义表达优先级。

全部展开后的同步模块必须连接到同一个顶层 clock 输入的别名集合。独立的第二时钟、逻辑生成的门控时钟、下降沿状态更新均在逻辑综合中报错。使能用保持下一状态表达，不能偷偷转换为未经验证的门控时钟。

reg 初始为“尚无有效逻辑值”。这是验证器状态，不是可综合的第三种位值。复位边沿后才获得有效复位值；未经复位的状态允许在未被选择的分支中保持无效，但一旦影响有效输出比较、控制选择或待提交数据，就报告可定位诊断。实际方块初始化另由组件规范约定，不能依赖逻辑验证器给物理电路写寄存器。

## 9. 逻辑模型与物理结果

逻辑模型定义函数和离散状态转移，不以零延迟门替换 simulator 的方块规则。每个逻辑时钟周期对应物理接口上约定的有效采样，时间、脉宽、负载、放置历史与环境条件由[物理规范](physicalSpec.md)约束。

布尔等价只覆盖指定逻辑接口；不能据此消除会触发时钟、活塞或其他边沿敏感器件的短暂变化。映射必须保持约定周期数，不允许暗中流水化、重定时或用固定输出替代未实现器件。

未绑定物理组件的 HDL 仍可通过逻辑检查；物理构建必须报告无法映射。结构组件没有可信逻辑模型时，包含它的设计只能执行完整方块测试，不能将逻辑测试显示为通过。

## 10. 版本、实现与扩展规则

0.1 的语法和语义作为一个版本整体解析。将来改变位宽、复位、采样或连接规则必须改变语言版本，不能仅升级器件库就悄悄改变源码含义。

编译器采用 C++20；核心前端与浏览器、网络和 Minecraft 进程解耦。编译期数学使用有定义的运算，定宽数据按规范进行截位和符号解释；不能依赖宿主整数溢出、移位和容器迭代顺序。

未知操作、关键字、必需配置项、组件能力或格式版本默认报错。0.1 没有隐式扩展模式；实验能力必须使用另一个明确标识的语言/目标配置，不能写入正式兼容结果。
