# 紧凑 8 位加法器

[`adder8.json`](adder8.json) 可通过 simulator 的 **工程 → 导入 .vmcb / JSON…** 直接打开。

1. 点击“适合画面”，查看全部电路；滚轮放大单个位的走线。
2. 选择 **10× · 200 gt/s**，点击“运行”。默认输入 **37 + 19 + 0 = 56**。
3. 波形的前九行依次为 `C8, S7, S6, …, S0`，稳定后应为 **0 00111000**。高电平显示 15，低电平显示 0。
4. 按 `5` 切换“操作”，点击拉杆修改输入。蓝色支撑是 A，橙色是 B，黄色是进位，绿色是结果。拉杆接通表示该位为 1。

这是无符号加法：`C8:S7…S0 = A + B + Cin`，结果范围 0–511。灯亮表示 1。

## 找到输入与结果

每一级沿 Z 轴排列，`i = 0…7`；Z 最小的一排是最低位，位权依次为 1、2、4、8、16、32、64、128。坐标顺序为 `[x,y,z]`。

| 器件 | 坐标 |
| --- | --- |
| Aᵢ 拉杆（蓝） | `[-5, 4, 22×i]` |
| Bᵢ 拉杆（橙） | `[-5, 4, 22×i+3]` |
| Cin 拉杆（黄，只有一个） | `[63, 4, 6]` |
| Sᵢ 结果灯（绿） | `[64, 4, 22×i]` |
| Cᵢ₊₁ 进位灯（黄） | `[61, 4, 22×i+11]` |

文件内 `example.ports` 也列出了全部坐标；该字段是样例说明，仿真结果由方块电路产生。

可试 `255 + 1 = 256`（只有 C8 亮）、`255 + 255 + 1 = 511`（九位全亮）、`0 + 0 = 0`（九位全灭）。连续修改多根拉杆时会出现中间结果；待进位传播完毕后读取最终值。原速下较慢，建议用 10×；“不限速”适合直接看稳定结果。

## 电路与验证

共 **8,622 个方块**，包含 17 根输入拉杆、72 个火把 NOR 门、粉线、中继器、8 个结果灯和 8 个进位灯。信号总线位于 Y=4，上跨走线位于 Y=7，跨位进位位于 Y=10；各门靠近自己的输入总线，可使用编辑层剖切查看内部。

与第一版相比，压缩后的尺寸以方块坐标包围盒计，三个方向均包含端点：

| 指标 | 第一版 | 紧凑版 | 减少 |
| --- | ---: | ---: | ---: |
| 尺寸 X × Y × Z | 96 × 14 × 567 | 74 × 11 × 180 | — |
| 占地 X × Z | 54,432 | 13,320 | 75.5% |
| 包围盒体积 | 762,048 | 146,520 | 80.8% |
| 实际方块数 | 19,780 | 8,622 | 56.4% |
| 中继器数 | 1,235 | 605 | 51.0% |

压缩方法：按信号的使用范围复用五条总线，门间距从 8 缩到 6，位间距从 72 缩到 22，布线层间距从 4 缩到 3。五个门可直接爬升进入已腾空的输出总线，其余四个门使用上跨走线。进位输入从右向左传输，始终保留独立总线；不同信号之间保留隔离间隙。此布局是该样例的固定走线，不是通用自动布线器。

每个全加器使用以下九个 NOR 门，`nor(x,y) = !(x || y)`：

```text
p = nor(a, b)       q = nor(a, p)       r = nor(b, p)
s = nor(q, r)       t = nor(s, c)
u = nor(s, t)       v = nor(c, t)
sum = nor(u, v)     carry = nor(p, t)
```

已在当前 C++ simulator 的 Release 构建中验证 **780 组输入及切换**：逐位全加器真值表、边界值、溢出、256 组贯穿进位、固定种子随机输入，以及清零、恢复默认输入。逐一检查全部结果灯和每级进位灯，并确认没有方块消失、残留计划事件或运行中止。

默认上电最后一个已记录输出边沿由 **320 gt 降到 174 gt**；相同 780 组测试中观察到的最长输出稳定时间由 **662 gt 降到 370 gt**，10× 速度下约 1.85 秒。这是已测场景结果，不是所有输入时序的严格上界。快速反复拨动输入仍受红石火把熄灭保护等器件机制影响。

该样例通过了当前 simulator 的验证；未对整份加法器做 Minecraft Java 26.2 原版差分验证，不据此宣称整机原版兼容。

重新生成与验证（在仓库根目录）：

```sh
python3 simulator/tools/buildAdder8.py
cmake --build simulator/build --target adderExampleTests -j 6
ctest --test-dir simulator/build -R '^adderExampleTests$' --output-on-failure
```
