## 已集成内容

- 运输船/竹筏容器：`java26_2BoatContainers`，89 帧，覆盖吸取、推出、失败逐刻重试、候选顺序与世界随机源。九种船和竹筏的注册类型、槽位数有源码核对；动态捕获覆盖橡木运输船和运输竹筏，不能泛称所有材质均实测。
- 漏斗矿车主动吸取：固定格中心协议下的容器吸取、唤醒、阶段执行和快照回归。**方块源查上面第二格，实体源用 `[Y+1.5,Y+2.5]` 查询盒**，二者不能共用整格索引。这项有源码与单元回归，仍缺完整的主动吸取原版时间线。
- 容器实体按注册包围盒跨格可见：矿车覆盖两格，船覆盖 18 格，访问同一声明身份和库存；实体字段不因查询格不同而复制。
- `java26_2EjectHopper` 已加入核心回归：71 帧、2 个观察点，比对原版抛出初始位置/速度和后续外部落点声明、漏斗吸取。
- 铁轨过期快照的实时方块身份守卫，以及堆肥桶输出与实体目标传输相关修复。

## Codex 收尾修复

1. 跨格分支遗留的清理测试揭示：换掉声明格方块时原有协议清除运行数据，但没有清理新实体索引。现在同步清除 `entityCells` 和 `cartCells`，避免访问失效记录。测试保留了 Claude 未提交的改动；原工作树和补丁均保留。
2. `DiodeBlock.neighborChanged` 的实时方块身份守卫同样适用于比较器和中继器。旧快照投递到已经替换成石头的无支撑格时，旧实现会删掉石头；新增回归验证方块、运行状态和队列均不被修改。
3. 捕获器对一格内多个可能的抛出源明确报歧义，避免把“最近”误称为“唯一”。现有动态证据仍只有单抛出器。
4. 原版重放 CLI 将相对输出路径解析为绝对路径，避免 Java 在缓存工作目录寻找不存在的场景文件。保留首次失败日志，修复后重新运行。
5. 修正证据措辞：船场景未同时放置方块容器和实体，不能独立证明方块容器短路；该规则来自源码。脚本 LF 设置也不等于 JSON 哈希统一，随附哈希按实际文件字节计算。

## 不能关闭的缺口

- 抛出反馈场景第 18 刻将真实飞行物替换为外部声明的落点，第 56 刻被漏斗吸取。自然飞行探针与交接场景在此锁定漏斗设置下的可吸取存在区间一致；**不能据此声明实现或逐刻验证了物品运动**。捕获器会清除交接柱体内真实物品，这是显式刺激，非无干预观察。
- 多格实体候选按声明坐标排序；原版同一分区按生成/插入顺序。跨格混合候选的身份选择尚不等价。当前候选查询遍历声明表，尚无大规模性能证据。
- 容器实体仍是固定中心位置输入，方块替换时清除同格声明是既有协议约定，不是原版实体生命周期。移动、浮力、挤出、完整实体生命周期未实现。
- 漏斗矿车主动吸取、跨格几何的新组合仍需要隔离原版时间线；已有船容器差分不能替代它们。
- 普通轨快照独立动态见证、更多复杂 BUD/零刻组合、更新抑制分类、票据传播/异步实体加载及 UI 仍未完成。保留预算耗尽暂停策略，不以丢弃事件模拟正确执行。
