# 标靶命中

标靶由命中面与格内坐标计算信号，环境输入示例：

```json
{"face":"up","hit":[0.5,1,0.5],"arrow":true}
```

`face` 使用 `up/down/north/south/east/west`，`hit` 是按 X、Y、Z 排列的 0–1 格内坐标。界面自动把垂直于命中面的坐标设为该面边界；箭矢类型默认 true。外部调用必须给出合法坐标与命中面，不能直接给 `value`。手动编辑方块 `power` 仍是状态编辑，不等同于投射物命中。

内核先把格内坐标加到方块坐标，按原版从世界坐标双精度数求小数部分。忽略垂直于命中面的轴，取另两轴离中心距离的最大值 `d`：

`power = max(1, ceil(15 * clamp((0.5 - d) / 0.5, 0, 1)))`

中心输出 15，边缘至少输出 1。不能只在前端根据归一化坐标计算，因为大坐标加法与强度阈值附近的舍入会改变结果。原版公式使用正向小数部分，负坐标不能用 C++ 带符号余数替代。

箭矢脉冲持续 20 gt，其他投射物为 8 gt。存在同类待执行计划刻时，再次命中不改变当前信号，也不延长结束时刻。重新放置一个带电标靶会清零；若同坐标仍有原标靶的待执行计划刻，则保留指定电量直到该计划刻执行。同类型属性修改不走新器件放置清零路径。

本项目只输入命中结果，不计算射击弹道、伤害、玩家统计与进度。标靶标记为 `externalStimulus`。点击右侧靶面图或输入格内坐标，再选择箭或其他投射物即可测试。

原版证据：`ExportTarget.java` 直接调用固定 26.2 的私有强度函数，4,272 个样本覆盖六朝向、四组世界坐标、阈值与相邻浮点数。`captureTargets.py` 在真实 GameTest 中调用原版命中更新路径，用箭和雪球对象确定持续时间，原版调度器执行后续释放；53 刻 / 26 点状态与粉线差分通过。没有模拟器自行生成的“预期公式”作为唯一判断依据。
