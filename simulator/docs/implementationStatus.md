# simulator 实施记录

## 授权和目标

用户已批准开始实现 C++ 原生仿真 + 浏览器 Three.js 方案。代码统一位于 simulator/，使用驼峰命名；每个经过验证的大更新 Git 提交，说明不超过 20 字。

默认先在当前 macOS 开发机验证，工程编辑操作为主，目标规模遵循设计。TNT 复制、完整流体、矿车计算机与生物 AI 机器不在本模块范围内。

## 已完成的核心基础

- C++20 / CMake，16³ 稀疏分块、连续方块状态表、确定性邻居更新栈和计划刻队列。
- 26.2 服务端 SHA-1 校验，导出 1,196 种原版方块状态定义、方向供电和支撑面数据；数据覆盖不代表全部器件实现。
- 当前可执行器件：结构方块、红石块、拉杆、按钮、红石粉、火把、中继器、比较器、侦测器、红石灯、铜灯、活塞/黏性活塞、黏液/蜂蜜黏连、门/活板门/栅栏门，以及环境输入驱动的压力板、阳光探测器、避雷针、讲台、标靶和部分状态读数器件。普通箱、陷阱箱、木桶和漏斗支持真实库存与传输。具体环境边界见 [environmentInputs.md](environmentInputs.md)。其他器件暂时拒绝放置。
- 原生探针、同刻有序边沿、触发暂停、VCD、工程文件与包含队列/内部状态的运行快照、原子导入。
- Release 与 ASAN/UBSAN 构建的 29 项测试通过。包含全部原版状态的属性往返、负坐标、时序与快照测试，五组真实 26.2 GameTest 状态差分（25 刻 / 47 点、29 刻 / 32 点、17 刻 / 14 点、65 刻 / 25 点、195 刻 / 5 点），以及阳光探测器 11,536 个数值对照。
- 差分只是这些场景的证据，不代表更新顺序、所有位置/朝向或全部器件完整兼容。
