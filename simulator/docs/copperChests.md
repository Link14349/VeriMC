# 铜箱

支持四种氧化程度及对应涂蜡版本，共八种铜箱。每个物理方块 27 槽，合并为 54 槽。比较器读取、开箱人数、箱盖阻挡、漏斗和投掷器传输复用容器模型；物品按真实槽位保存。

与普通箱子的区别：

- 不同铜箱变体可以连接；普通箱子和陷阱箱不能与铜箱组成双箱。
- 编辑器新放置第二半部时，按照原版普通放置规则，先检查朝向顺时针侧，再检查逆时针侧。合并后选择两半中氧化程度较低的变体。
- 两半涂蜡状态不同，合并结果去蜡；两半都涂蜡则保留。自然氧化随机刻仍按实验环境设置关闭。
- 配对方向上的邻居形状更新同步铜箱变体。显式替换某半部的铜箱状态会保留它的库存、查看人数，并同步另一半；不会把变体转换当作拆除容器清空库存。
- 双箱拆开后各半保留对应物理槽位；与非铜箱的替换不保留旧铜箱内部数据。

未模拟铜傀儡 AI、猫的坐箱行为、玩家菜单实体或连续箱盖碰撞。开箱人数是显式环境输入；图形开合由该状态驱动。声音和内部游戏事件仍待统一事件系统补齐。涂蜡/刮蜡物品操作还未提供专用工具；可通过方块状态替换设置变体。普通右键放置规则已覆盖，玩家蹲下指定连接侧的操作暂未作为独立编辑器交互提供。

## 原版验证

`captureCopperChests.py` 覆盖八变体 × 八变体的 64 种配对，轮换四个水平朝向；使用真正的原版 `getStateForPlacement` 与模拟玩家朝向，随后由原版形状更新执行合并。25 刻 / 132 点逐帧比较方块状态、库存与模拟读数，包含单半替换、去蜡、拆分重连、漏斗传输和比较器。

原生测试额外覆盖转换期间快照恢复、查看人数保留和替换成普通箱子时分离。WebSocket 测试覆盖配对、开箱、转换撤销与运行快照；浏览器验证朝东双箱、54 槽及两半同步开盖。规则依据为固定 26.2 的 `CopperChestBlock`、`WeatheringCopperChestBlock`、`ChestBlock` 与 `LevelChunk` 的方块实体保留条件。
