# 钟

钟支持供电上升沿、手动敲击、指定命中面与高度，以及地面、天花板、单墙和双墙支撑。敲响时立即产生 `BLOCK_CHANGE` 游戏事件，幽匿感测体读取频率 11。钟自身不输出红石信号。

## 输入与支撑

环境面板的“敲钟”选择当前安装形式允许的方向；精确输入使用：

```json
{"face":"north","height":0.5}
```

`height` 是格内高度，范围 0–1。上、下面不能敲响；水平面要求命中高度不超过原版单精度 `0.8124F` 扩展为双精度后的阈值。保留先加世界坐标再相减的运算，避免大坐标处边界舍入变化。地面钟要求命中方向与朝向同轴，墙挂钟要求不同轴，天花板钟允许所有水平侧面。合法但未命中可敲区域的输入不会产生振动。

`{"ring":true}` 直接请求一次无命中面约束的敲响，用于外部模型已经判定的触发；它不模拟爆炸过程。重复敲击再次发出事件并重置摆动时间。

朝向和支撑形式由编辑器明确指定。地面检查完整上表面，天花板检查稳定的底部中心支撑，墙挂检查所朝方向的支撑。支撑变化按原版转换单双墙及朝向；唯一支撑移除时破坏钟。没有根据鼠标撞击面自动推断放置形式。

## 执行与快照

敲击调用立即记录方向与摆动状态，方块事件阶段再重置显示状态；不同方向事件保留顺序，相同待执行事件去重。没有生物 AI 时，中间摆动刻既不通知方块也不消耗世界随机数，因此只安排原版第 50 个方块实体刻的停止事件。空闲钟不逐刻扫描。

运行快照保存敲击记录、方块事件、注册顺序和停止排期，并交叉验证；移除后重新放置不会继承旧的停止事件。摆动中的钟导出电路时提示保存运行快照，空闲电路导出清除过去运行的诊断记录。

检查面板显示次数与状态，三维用明亮颜色标记摆动。没有声音播放、村民响应、袭击者查找或发光效果，这些生物行为不属于当前范围。器件标记部分支持，图形没有复制原版连续摆动动画。

同批修正音符盒放置行为：在已有电源旁新放置音符盒或钟，不额外调用自身的邻居通知；之后真实邻居变化才触发相应上升沿。

## 验证来源

固定 Java 26.2 的 `BellBlock`、`BellBlockEntity`、`FaceAttachedHorizontalDirectionalBlock` 与 `unstable_bottom_center` 标签。

- `captureBells.py`：原版 123 刻 / 34 点，四种安装 × 四个朝向，供电、命中、重复敲击、摆动停止、支撑拆换、感测体和已有电源旁放置。
- `ExportBellHits.java`：2,688 次原版命中判断，覆盖安装、朝向、六面、四种世界高度及阈值相邻浮点数。
- 原生专项覆盖事件顺序、停止时刻、快照、错误队列、移除重放置、世界随机源不变及空闲休眠。Release/ASAN/UBSAN 共 74 项测试通过。
- 钟、音符盒、振动和完整服务协议回归通过。浏览器手工放置钟，验证无效命中不计数、有效敲击及第 50 刻停止；控制台无错误。

原版源码、资源和 JAR 不随项目分发。
