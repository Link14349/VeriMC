# 第一人称与物品栏

2026-09-08：新增窗口内第一人称飞行搭建、原生浏览器全屏与 E 物品列表。浏览器处理相机和输入，C++ 仍是电路与库存的权威状态；本次没有修改仿真内核。

按用户偏好，第一人称方块交互距离延长至 20 格。拆除、贴面放置、右键使用、中键取物和准星高亮共用同一射线范围；超距或无实际方块命中时不操作。

## 操作

| 输入 | 第一人称搭建 |
| --- | --- |
| 视图右上角“第一人称” | 进入窗口内飞行搭建，并申请鼠标锁定 |
| “全屏” / F11 | 进入或退出原生全屏；进入全屏同时启用第一人称 |
| 鼠标移动 | 转动视角，准星保持中心 |
| 碰撞与重力（右上角） | 默认关：无重力自由飞行；开：重力行走，启用身体碰撞 |
| WASD / Ctrl | 水平移动 / 加速 |
| Space / Shift | 行走时 Space 跳跃；飞行时上升 / 下降 |
| 双击 Space | 开启碰撞时切换行走 / 飞行；飞行仍有碰撞 |
| 飞行落地 | 开启碰撞时自动退出飞行、恢复重力行走；单按 Space 跳跃，双击可再次起飞 |
| 行走遇到障碍 | 自动跨过低坎或跳上一格高的方块；按住 Shift 暂时抑制自动跳跃 |
| 左键 / 右键 | 拆除 / 优先使用器件，否则贴面放置 |
| Shift + 右键 | 持有方块时绕过使用，贴面放置 |
| 中键 | 取准星方块；已有物品则切换对应格，否则替换当前格 |
| 1–9 / 滚轮 | 切换九格快捷栏，滚轮首尾循环 |
| E | 打开物品列表；非输入框中再按 E 关闭并尝试恢复鼠标锁定 |
| Esc | 物品栏内关闭物品栏并直接恢复搭建；世界中释放鼠标，显示“继续搭建”；再按一次关闭面板并恢复搭建 |
| Enter / 数字键盘 Enter | 运行 / 暂停仿真；长按不重复切换，物品栏与输入框内不触发 |
| 返回工作台 | 恢复原有轨道视角与编辑工具，退出本应用全屏 |

全屏状态根据 `fullscreenchange` 更新。浏览器拒绝全屏或鼠标锁定时显示可见错误，不假装已经启用。全屏以整个应用为根，物品列表、器件窗口和错误提示仍可显示。浏览器/系统可能先处理 Esc 或 F11，界面跟随实际状态。

物品列表提供当前内核登记方块的中文/ID 搜索与分类，保留支持等级。活塞头、移动活塞等不当作独立物品列出。点击物品拿起，再点快捷栏格子放入；Shift 点击直接分配当前格；焦点在搜索框外时，悬停物品按 1–9 指定格；右键格子清空。快捷栏为空时不能放置，仍可操作器件。快捷栏目前保留在当前页面会话中，不写入工程文件。

原生 dialog 限制焦点。搜索框的字母、数字保持输入用途；物品栏内 Enter、F、Delete、WASD 不传给世界。打开窗口、失去锁定、失焦和页面隐藏时清空移动与连按状态。第一次捕获鼠标的点击不执行拆放。连续拆放采用受限的 250 ms 间隔，是编辑交互节流，不改变仿真游戏刻。

物品栏内按 Esc 时，等待松键再关闭并恢复鼠标锁；恢复期间不显示“继续搭建”面板，避免把同一次 Esc 误当作世界中的暂停操作。E 和关闭按钮同样直接返回搭建。在世界中按 Esc 释放鼠标，再按一次 Esc 松键后关闭“继续搭建”面板并重新捕获鼠标；长按不会反复开关。Enter 在第一人称与全屏共用工作台的运行 / 暂停分派，并保留离线、输入框、模态窗口及文件读写保护。

右键拉杆、按钮、中继器、比较器、红石粉、音符盒、门等转发已支持的 `interact`；箱、漏斗、投掷器等打开现有库存/环境面板。讲台、堆肥桶只显示对应环境面板，不伪造库存操作。

工作台共用上述器件操作分派：模式 4 的左右键均操作命中器件；模式 2 右键优先操作，不能操作时才相邻放置，Shift + 右键可绕过操作。工作台按当前待放置方块判断是否持有物品，不受第一人称快捷栏空格影响。拖动判定先于动作分派，右键旋转视角不会误触器件。

## 机制依据与边界

基础键位参考 [Minecraft Controls](https://www.minecraft.net/en-us/article/minecraft-controls)。常用器件朝向对照本地固定 Java Edition 26.2 参考源码的 `getStateForPlacement`：DiodeBlock、PistonBaseBlock、ObserverBlock、DispenserBlock、HopperBlock、FaceAttachedHorizontalDirectionalBlock、BarrelBlock、SlabBlock 等。中继器/比较器指向水平视向的反方向；侦测器朝视向，活塞/投掷器朝其反方向；拉杆/按钮依命中面选择 floor/wall/ceiling。半砖和活板门使用实际命中高度选择上/下半格。中键活塞头按 type 返回对应活塞，移动活塞不取物。

参考 server SHA1：`823e2250d24b3ddac457a60c92a6a941943fcd6a`；manifest SHA1：`3592ebc61c6b6c33bb8228fe5a9e90221df0be68`。本次浏览器测试不等价于新增原版差分测试。

第一人称与全屏共用右上角“碰撞与重力”开关。默认关闭以保留无重力自由飞行；开启后默认行走，静止也受重力，落地停稳，单按 Space 跳跃。连续两次独立 Space 按下间隔不超过 300 ms 时切换飞行；按键自动重复不会触发切换。飞行暂停重力但继续碰撞；再次双击退出飞行后恢复下落。行走时 Shift 不产生向下位移；飞行时 Space / Shift 升降。开关在页面会话内保留，重新进入第一人称时，启用碰撞的模式从行走开始。

开启碰撞时使用浏览器端身体体积：宽 0.6、高 1.8 格，眼睛距脚底 1.62 格。移动按整段位移扫掠，先处理升降，再沿水平轴裁剪，支持冲刺防穿透和贴墙滑动。飞行下降或停在方块顶面时，按最终脚底支撑判断落地并自动恢复行走，同步更新界面状态；精确抵达顶面也算落地，侧面/头顶接触不算，斜向飞出台边后无支撑则继续飞行。自动落地清空之前的双击计时，落地后需重新双击 Space 起飞。普通轨道工作台保持自由移动。

碰撞默认复用实体部件的简化包围盒，不包含纹理面；低矮红石器件改用独立底板盒：中继器/比较器高 1/8 格、阳光探测器高 3/8 格、幽匿感测体/校频感测体高 1/2 格。上方火把、锁定杆、网格、天线和晶体仍显示并可拾取，但不阻挡人物。底板盒保留运动偏移，世界与放置预览使用同一规则；供电、延迟、模式和朝向不改变底板高度。半砖、门、活板门和运动活塞随实际显示状态更新。红石粉、火把、拉杆、按钮、压力板、铁轨、绊线及绊线钩不阻挡身体，打开的栅栏门允许通过。每个方块修改时替换空间索引条目；索引按几何实际范围登记，因此移动部件跨原方块格仍参与检测。全量导入/撤销清空重建；正常移动只查询扫掠范围邻近桶，既不扫描整个世界，也不缓存依赖当前位置的碰撞结果。

碰撞行走受到水平阻挡且脚下有支撑时，先尝试不超过 0.6 格的跨步，依次验证上方、水平路径和落脚支撑；低底板与半砖直接跨过，不触发完整跳跃。跨步不可行时，仅在一格高以内的顶面可达、跳跃头部空间足够时施加正常跳跃初速，由同一重力与碰撞求解器走完整跳跃轨迹。高墙、低顶板、空中状态不会触发自动跳跃；按住 Shift 可暂时抑制自动跳跃，但仍可跨低坎。飞行与关闭碰撞时不启用自动跨步/跳跃。这是编辑器便利行为，不宣称复刻全部原版自动跳跃判定。

开启碰撞时，贴面放置前检测待放实体几何（门包括自动生成的上半格）与身体是否重叠，避免自行埋入方块。关闭碰撞时允许穿过方块及身体内放置，开启时再执行脱困。入场、导入或仿真变化包住身体时，沿六个方向搜索空位并选择较近出口；极大实体内部超过局部搜索预算时移到全部几何上方。该恢复是编辑器脱困，不模拟原版活塞推人。未把相机作为 C++ 玩家实体，不会因接触自动触发压力板、绊线、振动等环境输入。

碰撞尚非全部原版 VoxelShape；细节部件使用轴对齐包围盒，箱盖、栅栏等边界按简化模型处理。重力使用编辑器参数（24 格/秒²、跳跃初速 8 格/秒、下落速度上限 60 格/秒），最大 1/120 秒分步积分，独立于 C++ 游戏刻；行走 4.3 格/秒、加速 6.5 格/秒，飞行沿用 10.89 / 21.78 格/秒。打开物品栏等模态窗口、失锁、失焦时暂停人物运动并清空跳跃/双击输入，不累积后台落差。尚未实现蹲下体积、摔落伤害、物品堆叠与消耗、副手、Q 掉落、原版容器 GUI。门铰链、双箱 Shift 配对、半砖合并、所有可替换方块与复杂放置上下文仍需专项实现。钟的直接点击沿用现有内核有效敲击方向，未复现全部命中面细节。因此不能称为与 Minecraft 全部交互完全一致。

## 验证

- `npm run build`：TypeScript 和生产构建。
- `node --test simulator/tests/interactionTests.mjs simulator/tests/webTests.mjs`：39 项逻辑、渲染和协议回归，包含朝向/物品形式/右键分派。
- `creativeBrowserTests.mjs`：真实 Chrome Pointer Lock / Fullscreen API、捕获前不编辑、20 格范围、左右中键、Shift、滚轮、清键、E/搜索隔离、九格快捷栏、Esc 双向开关菜单、Enter / 数字键盘 Enter 运行暂停与长按/离线保护。

- `playerCollisionBrowserTests.mjs`：真实锁鼠验证冲刺撞墙、滑墙、地板/头顶、负坐标、增量拆除、半砖/门/活板门/栅栏门、非实体器件、跨格运动、脱困、放置排斥、重力/跳跃、双 Space、失锁暂停和碰撞开关。
- `interactionBrowserTests.mjs`、`viewportTests.mjs`：原有工作台、预览、方块表面命中与键盘移动回归。

浏览器测试使用 Vite `127.0.0.1:5179` 与受控内核夹具；可以用 `NODE_PATH` 指向环境的 Playwright。截图保存在忽略的 `simulator/testResults/`。

本次结果：39 项逻辑测试、28 项浏览器检查通过，生产构建通过。另在运行中的 C++ 服务只读验收，物品列表加载 437 个可选条目，1440 × 1000 与 680 × 700 布局正常，未发现页面脚本错误。浏览器测试修正了原有测试夹具未更新相机世界矩阵的时序依赖，并用 1e-8 容差判断浮点相机静止，仍验证真实持续移动和失焦停止。

碰撞和重力的最终验证结果见实施记录；这些编辑器测试不等价于原版玩家实体差分验证。
