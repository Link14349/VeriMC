# 第一人称与物品栏

2026-09-08：新增窗口内第一人称飞行搭建、原生浏览器全屏与 E 物品列表。浏览器处理相机和输入，C++ 仍是电路与库存的权威状态；本次没有修改仿真内核。

## 操作

| 输入 | 第一人称搭建 |
| --- | --- |
| 视图右上角“第一人称” | 进入窗口内飞行搭建，并申请鼠标锁定 |
| “全屏” / F11 | 进入或退出原生全屏；进入全屏同时启用第一人称 |
| 鼠标移动 | 转动视角，准星保持中心 |
| WASD / Space / Shift / Ctrl | 水平移动 / 上升 / 下降 / 加速 |
| 左键 / 右键 | 拆除 / 优先使用器件，否则贴面放置 |
| Shift + 右键 | 持有方块时绕过使用，贴面放置 |
| 中键 | 取准星方块；已有物品则切换对应格，否则替换当前格 |
| 1–9 / 滚轮 | 切换九格快捷栏，滚轮首尾循环 |
| E | 打开物品列表；非输入框中再按 E 关闭并尝试恢复鼠标锁定 |
| Esc | 物品栏内关闭物品栏并直接恢复搭建；世界中释放鼠标，显示“继续搭建” |
| 返回工作台 | 恢复原有轨道视角与编辑工具，退出本应用全屏 |

全屏状态根据 `fullscreenchange` 更新。浏览器拒绝全屏或鼠标锁定时显示可见错误，不假装已经启用。全屏以整个应用为根，物品列表、器件窗口和错误提示仍可显示。浏览器/系统可能先处理 Esc 或 F11，界面跟随实际状态。

物品列表提供当前内核登记方块的中文/ID 搜索与分类，保留支持等级。活塞头、移动活塞等不当作独立物品列出。点击物品拿起，再点快捷栏格子放入；Shift 点击直接分配当前格；焦点在搜索框外时，悬停物品按 1–9 指定格；右键格子清空。快捷栏为空时不能放置，仍可操作器件。快捷栏目前保留在当前页面会话中，不写入工程文件。

原生 dialog 限制焦点。搜索框的字母、数字保持输入用途；物品栏内 Enter、F、Delete、WASD 不传给世界。打开窗口、失去锁定、失焦和页面隐藏时清空移动与连按状态。第一次捕获鼠标的点击不执行拆放。连续拆放采用受限的 250 ms 间隔，是编辑交互节流，不改变仿真游戏刻。

物品栏内按 Esc 时，等待松键再关闭并恢复鼠标锁；恢复期间不显示“继续搭建”面板，避免把同一次 Esc 误当作世界中的暂停操作。E 和关闭按钮同样直接返回搭建；在世界中单独按 Esc 仍释放鼠标。

右键拉杆、按钮、中继器、比较器、红石粉、音符盒、门等转发已支持的 `interact`；箱、漏斗、投掷器等打开现有库存/环境面板。讲台、堆肥桶只显示对应环境面板，不伪造库存操作。

## 机制依据与边界

基础键位参考 [Minecraft Controls](https://www.minecraft.net/en-us/article/minecraft-controls)。常用器件朝向对照本地固定 Java Edition 26.2 参考源码的 `getStateForPlacement`：DiodeBlock、PistonBaseBlock、ObserverBlock、DispenserBlock、HopperBlock、FaceAttachedHorizontalDirectionalBlock、BarrelBlock、SlabBlock 等。中继器/比较器指向水平视向的反方向；侦测器朝视向，活塞/投掷器朝其反方向；拉杆/按钮依命中面选择 floor/wall/ceiling。半砖和活板门使用实际命中高度选择上/下半格。中键活塞头按 type 返回对应活塞，移动活塞不取物。

参考 server SHA1：`823e2250d24b3ddac457a60c92a6a941943fcd6a`；manifest SHA1：`3592ebc61c6b6c33bb8228fe5a9e90221df0be68`。本次浏览器测试不等价于新增原版差分测试。

当前是飞行搭建相机，未实现玩家重力/碰撞、双击 Space 切换走路/飞行、物品堆叠与消耗、副手、Q 掉落、原版容器 GUI。射线复用现有简化器件几何，尚非全部原版 VoxelShape。门铰链、双箱 Shift 配对、半砖合并、所有可替换方块与复杂放置上下文仍需专项实现。钟的直接点击沿用现有内核有效敲击方向，未复现全部命中面细节。因此不能称为与 Minecraft 全部交互完全一致。

## 验证

- `npm run build`：TypeScript 和生产构建。
- `node --test simulator/tests/interactionTests.mjs simulator/tests/webTests.mjs`：39 项逻辑、渲染和协议回归，包含朝向/物品形式/右键分派。
- `creativeBrowserTests.mjs`：真实 Chrome Pointer Lock / Fullscreen API、捕获前不编辑、5 格范围、左右中键、Shift、滚轮、清键、E/搜索隔离、九格快捷栏。
- `interactionBrowserTests.mjs`、`viewportTests.mjs`：原有工作台、预览、方块表面命中与键盘移动回归。

浏览器测试使用 Vite `127.0.0.1:5179` 与受控内核夹具；可以用 `NODE_PATH` 指向环境的 Playwright。截图保存在忽略的 `simulator/testResults/`。

本次结果：39 项逻辑测试、28 项浏览器检查通过，生产构建通过。另在运行中的 C++ 服务只读验收，物品列表加载 437 个可选条目，1440 × 1000 与 680 × 700 布局正常，未发现页面脚本错误。浏览器测试修正了原有测试夹具未更新相机世界矩阵的时序依赖，并用 1e-8 容差判断浮点相机静止，仍验证真实持续移动和失焦停止。
