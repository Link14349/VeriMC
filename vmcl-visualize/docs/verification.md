## 本次发现并修复

1. ELK bundled 版本放在 Worker 中直接构造，因环境探测失败出现 `_Worker is not a constructor`。改为 ELK API 配合明确创建的真实 Worker。
2. 不能把所有 output 节点都固定到最右层：子模块 output 可能继续驱动下一节点。现在只对没有出边的 output 施加该约束，并以 RippleAdder 布局回归覆盖。
